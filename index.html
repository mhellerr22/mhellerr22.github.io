ClipWatch

ClipWatch is a personal tool for keeping track of public online clipping campaigns. It runs on its developer's own computer and keeps a Google Sheets dashboard up to date.

It is not a public service and has no other users: it is used only by its developer, for the developer's own Google account.

How ClipWatch uses Google

ClipWatch asks for one Google permission, "See, edit, create, and delete only the specific Google Drive files you use with this app" (drive.file). It uses it to create one Google Sheets workbook in the signed-in account's own Google Drive and to keep that workbook up to date. This permission does not let ClipWatch see any other file in the account.
